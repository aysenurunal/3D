# Capture Guide

3D generation quality depends heavily on the input photos. For the MVP, capture
5-6 clean photos:

1. Front
2. Left three-quarter view
3. Right three-quarter view
4. Back
5. Slightly elevated top view
6. Detail or problematic area

## Capture Rules

- Keep the object still and move the camera around it.
- Use soft, even lighting and avoid harsh shadows.
- Use a simple background with clear contrast against the object.
- Keep the full object visible in every photo.
- For shiny, transparent, or very thin objects, reduce reflections when possible.
- Place a known-size reference object nearby if real-world scale matters.

## MVP Note

The first InstantMesh workflow will run from one primary photo. The 5-6 photo set
will still be useful for:

- Selecting the best primary photo.
- Visually checking missing or incorrect geometry.
- Preparing a consistent data format for a future multi-view or alternative reconstruction adapter.
